## Earcut

- Upstream algorithm: https://github.com/mapbox/earcut (ISC) and its C++ port
  https://github.com/mapbox/earcut.hpp
- Location: `Runtime/ThirdParty/Earcut/Earcut.cs`
- Modified: yes. A caller-owned work budget is threaded through the solver so
  hostile geometry cannot drive the diagonal search into unbounded work; on
  exhaustion the solver stops and the caller falls back to fan triangulation.
  This mirrors the modification FragmentsUE applies to `earcut.hpp`.

## FlatBuffers

- Upstream: https://github.com/google/flatbuffers
- Copyright 2014 Google Inc.
- Location: `Runtime/Generated/` (bindings generated by `flatc --csharp` from
  `ThirdParty/index.fbs`) and the vendored Google.FlatBuffers C# runtime
  sources.
- Modified: yes, one function. `FlatBufferVerify.cs` `GetVRelOffset` narrowed
  the absolute vtable position to `Int16`, overflowing on any buffer whose
  vtables sit past byte 32767, and wrote caught exceptions to the console; the
  position is now kept as `int` and the console write is removed. Both changes
  are marked with `FragmentsUnity fix` comments in place.

Components (https://github.com/ThatOpen). The schema file in
